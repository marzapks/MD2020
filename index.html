CHORD / BASS PROGRESSION

Enter one chord per event. Set the bar and beat where it changes. Root-based colors are automatic; choose a custom color to override an individual chord.

CUE TIMELINE & MUSIC DIRECTOR COMMANDS

Cues can be scheduled by bar and beat, assigned to a voice, and given a lead-in. Count-ins are automatically generated when selected.
“Drums on 2” and “drums on 3” are entrance instructions. The selected count-in plays before the entrance; the target beat is called out at the correct point. For example, a one-bar count-in in 4/4 gives “1, 2, 3, 4” before the drums enter on the next bar’s beat 2 or 3.

DYNAMIC VISUAL EMPHASIS

Dynamic emphasis changes visual brightness and pulse strength; it never changes the programmed note colors or timing.

PROJECT LIBRARY

Project files keep your song structure, sections, chords, cues and settings. A .md2020set file packages multiple songs and the set order into one shareable file. Import it on another device running MD 2020. Folder names are stored as collections inside the app.

SETLIST / SHOW FOLDER

When enabled, the next setlist song loads and starts automatically after the current song finishes. The delay gives the band a transition window.

DEVICE / SESSION SYNC

This build can synchronize tabs/windows on the same browser using BroadcastChannel and can exchange projects through JSON. Imported .md2020 / .md2020set files let each bandmate load the same arrangement independently. Live conductor-to-band synchronization across separate devices still requires a hosted realtime relay; GitHub Pages alone does not provide that service.

VOICE & CLICK SETTINGS

Available speech voices depend on the browser and operating system. Selectable voice choices are populated from the device's speech synthesis engine.

PERFORMANCE SAFETY & AUDIO

Audio output routing is limited by the browser and connected device. For isolated click, voice, and backing-track feeds, use a compatible multichannel audio interface and a browser/device configuration that exposes those outputs.

KEYBOARD SHORTCUTS

Shortcuts are disabled while typing in text fields. Browser-reserved keys such as Escape may remain controlled by the browser.
